# Samsung 820 變頻前置式洗衣乾衣機 - 產品展示頁面 (Landing Page)

這是一個為「Samsung 820 變頻前置式洗衣乾衣機」打造的專屬產品展示網頁。採用簡約柔和的家居風格設計，旨在提供使用者舒適的瀏覽體驗，並清晰傳達產品的核心價值與特色。

## ✨ 專案特色 (Features)

*   **沉浸式首圖影片 (Video Hero Section)**：進入網頁即自動播放高畫質產品影片，快速吸引目光。
*   **響應式設計 (RWD)**：完美適配桌上型電腦、平板與智慧型手機，確保在任何裝置上都有最佳的視覺比例。
*   **圖文交錯排版 (Alternating Layout)**：產品特色區塊採用左右交錯的排版方式，讓閱讀動線流暢且具層次感。
*   **互動式常見問題 (Interactive FAQ)**：使用手風琴 (Accordion) 折疊效果，保持頁面整潔，提升使用者體驗。

## 🛠️ 技術棧 (Tech Stack)

*   **HTML5**：建構語意化網頁結構
*   **CSS3**：使用原生 CSS 撰寫樣式，包含 Flexbox 排版與 CSS 變數 (CSS Variables) 管理色彩計畫
*   **Vanilla JavaScript**：純原生 JS 實作互動功能，輕量且高效無依賴
